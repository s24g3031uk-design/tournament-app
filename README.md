# 🏆 トーナメントマネージャー

PC・スマートフォン両対応のシングルエリミネーション形式トーナメント管理アプリです。  
インストール不要 — `index.html` をブラウザで開くだけですぐに動作します。

---

## ✨ 主な機能

| 機能 | 説明 |
|------|------|
| 🔀 **シャッフル（抽選機能）** | **全員ランダム抽選（全シャッフル）** と **シード選手を固定して一般参加者のみシャッフル** の2モードを搭載 |
| ⭐ **シード設定（事前枠付け）** | 各参加者の横にある⭐ボタンで第1シード、第2シード...を個別に指定可能。上位2/4/8/16名の一括シード設定にも対応（シード選手はトーナメント最優遇枠に固定され、不戦勝を優先獲得） |
| 🔒 **合言葉（パスコード）ロック** | アクセス制限機能（合言葉: `0829`）を搭載。URLと合言葉を知っている関係者のみが利用可能 |
| 👥 **参加人数設定** | 2〜248名まで1名単位で細かく設定可能 |
| ↔️ **64人超の両翼レイアウト** | 人数が64人を超えた場合（128/256枠）、半分を右側に振り分けた左右分割（センター決勝型）の美しいトーナメント表に自動変換 |
| ⚡ **順番に勝敗登録** | トーナメント表の上（第1試合）から順番に次々と勝敗を入力可能。自動送り機能付き |
| 🔄 **不戦勝 (BYE)** | 参加者数が2の累乗に満たない場合は自動的に不戦勝を割り当て＆自動進出 |
| 📝 **参加者名の個別・一括登録** | 各参加者名の個別入力のほか、**テキストエリアに改行区切りで貼り付けて一行ずつ一括登録**する機能（行数に応じた参加人数自動調整オプション付き）を搭載 |
| 🥉 **3位決定戦** | ON/OFFで切り替え可能（準決勝の敗者を自動収集） |
| 🔴 **勝者ラインの赤色ハイライト** | 勝敗が決定すると、勝者が進出するトーナメント線が鮮やかな赤色（太線）に変化。勝ち上がりの軌跡が一目で分かります |
| 🌫️ **敗者の薄暗表示** | 勝敗決定後、敗者は半透明＋打ち消し線で表示され勝敗が一目で判別可能 |
| 📄 **PDF出力（余白カット＆大画面表示）** | 日本語大会名・日時・進行率・ブラケット図を余白なくジャストサイズでPDF出力（下部余白完全カット＆最大拡大表示） |
| 💾 **ローカル自動保存** | ブラウザに途中経過を自動保存し、いつでも再開可能 |
| 🖱️ **ドラッグスクロール** | PCでもスマホでも直感的に表をドラッグして全体を閲覧 |

---

## 🚀 使い方

### ローカルで使用する場合
`index.html` をダブルクリックしてブラウザで開くだけです。

### 共有する場合（GitHub / ダウンロード）
- **ファイル共有**: `index.html` を相手に送信するだけ（完全スタンドアロン）
- **GitHub Pages**: 本リポジトリをGitHubにプッシュし、Settings → Pages で `main` ブランチの root を選択すれば、Web上で即座に利用・共有できます。
